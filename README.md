<H1>Email Spam or Ham Detection📧</H1>
<p>This project classifies emails as spam or ham using AI and the Gmail API. The user interface is built with Streamlit, allowing users to fetch and display emails in a table format.</p>
<H1>Features</H1>
<p>
<ul>
<li>Fetch emails from Gmail</li>
  <li>Display sender, subject, and spam status</li>
  <li>Manual spam check by entering message text</li>
</ul>
</p>
<H1>Installation</H1>
<p><b>Required Libraries-</b><br>streamlit, pickle, nltk, imaplib, email, pandas</p>
<p><b>Additional Setup-</b><br> Enable secure app access in your Google account settings. <br> 
                      Create a Gmail app password for authentication</p>
<H1>Usage</H1>
<p>1. Fetch and Classify Emails</p>
<ul>
  <li>Enter your Gmail email and app password.</li>
  <li>Specify the number of emails to fetch.</li>
  <li>Click 'Fetch Emails' to display the emails along with their spam status.</li>
</ul>
<p>2. Manual Spam Check</p>
<u>
  <li>Enter the text of the message you want to check.</li>
  <li>Click 'Predict' to see if it's spam or not.</li>
</u>

<H1>Additional Notes</H1>
<ul>
  <li>Follow the Google's security guidelines for accessing Gmail via IMAP.</li>
  <li>Use the Gmail app password created in your Google account security settings for authentication.</li>
</ul>
